### ⚽ FootMind — Professor Virtual de Futebol

Plataforma que utiliza **inteligência artificial generativa** para responder dúvidas sobre futebol e ajudar usuários a aprender técnicas. Quando o usuário pergunta como executar um movimento, o FootMind apresenta uma explicação escrita, organizada em etapas, e pode indicar um vídeo do YouTube como apoio visual.

**O que o projeto oferece**
- Respostas para dúvidas relacionadas ao futebol.
- Explicações passo a passo sobre técnicas e movimentos.
- Recomendações de vídeos do YouTube para complementar o aprendizado.
